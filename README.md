## Stack

Vite · React 19 · TypeScript · three.js + React Three Fiber + drei + postprocessing ·
GSAP (ScrollTrigger, SplitText, Flip) · Lenis · Tailwind CSS 4 · zustand · shaders GLSL.
Tout le visuel est procédural : aucune image, vidéo ou modèle 3D à télécharger.

## Lancer en local

Prérequis : Node.js 20 ou plus récent.

```bash
npm install
npm run dev        # http://localhost:5173
```

Le site se déploie automatiquement sur GitHub Pages à chaque push sur `main`.

Le guide technique complet (contenu, couleurs, formulaire de contact, déploiement, architecture)
est dans [`docs/GUIDE.md`](docs/GUIDE.md).
